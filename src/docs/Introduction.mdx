# Lusintarr

React components for data-heavy and content-oriented applications.

Lusintarr is a component library focused on reusable building blocks for
data-heavy and content-oriented React applications.

The project is currently under active development.

## Planned components

- VirtualList
- DataState
- TextComposer
- TagPicker / CategoryPicker
